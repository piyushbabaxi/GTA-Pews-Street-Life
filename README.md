# GTA Pews: Street Life

A mobile-focused 3D open-world game set in Buxar, Bihar.

## Planned Features
- Realistic 3D player character
- Open-world city exploration
- Cars with enter and exit mechanics
- Police AI and wanted system
- Missions and pedestrians
- Android touch controls
- Installable Android APK

## Engine
Godot 4

## Platform
Android
